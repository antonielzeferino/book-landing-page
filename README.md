# O Poder da Disciplina - Página de Destino

Esta é uma página de destino simples criada para promover o livro *O Poder da Disciplina*. A página fornece informações chave sobre o livro, seus benefícios e uma chamada para ação (CTA) fácil para incentivar os usuários a fazer uma compra.

## Sobre

A página de destino é projetada para mostrar o livro *O Poder da Disciplina*, destacando seus principais benefícios e incentivando os visitantes a comprar o livro. Inclui seções como:

- **Seção Hero**: Capa do livro, título e slogan.
- **Sobre o Livro**: Informações sobre o que o livro oferece e como pode ajudar os leitores.
- **O Que Você Vai Aprender**: Principais lições ao ler o livro.
- **Depoimentos**: Avaliações de usuários.
- **Seção Compre Agora**: Chamada para ação para comprar o livro.

## Tecnologias Utilizadas

- **HTML5**: Para estruturar o conteúdo.
- **CSS3**: Para estilizar a página de destino.
- **Variáveis CSS**: Para gerenciar facilmente cores e tema.
- **Ícones SVG**: Para apelo visual (por exemplo, marcas de verificação na seção de benefícios).

## Instalação

Para executar este projeto localmente, siga estas etapas:

1. Clone o repositório:
  ```bash
  git clone https://github.com/seu-usuario/power-of-discipline-landing-page.git
  ```

2. Navegue até o diretório do projeto:
  ```bash
  cd power-of-discipline-landing-page
  ```

3. Abra `index.html` no seu navegador para visualizar a página de destino.

## Uso

1. Personalize o conteúdo:
  - Edite o texto no arquivo `index.html` para quaisquer alterações no texto.
  - Substitua a imagem na seção hero (`./assets/images/power.png`) pela capa do seu próprio livro, se necessário.
  
2. Atualize os estilos:
  - Os estilos estão contidos no arquivo `global.css`.
  - Você pode modificar as variáveis CSS para alterar o tema e as cores da página de destino.

3. Adicione quaisquer recursos ou seções adicionais conforme necessário, como:
  - Mais depoimentos ou avaliações de usuários.
  - Um temporizador de contagem regressiva para criar urgência para os usuários comprarem.
